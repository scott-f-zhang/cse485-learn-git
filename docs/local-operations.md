# Local Git Operations

## stash

Use `git stash push -u` to temporarily save work that is not ready to commit.

## cherry-pick

Use `git cherry-pick <commit>` to apply one specific commit from another branch onto the current branch.

## revert

Use `git revert <commit>` when you want to undo a change with a new commit instead of rewriting history.

## tag

Use `git tag -a <name> -m "message"` to mark a release or milestone in history.
